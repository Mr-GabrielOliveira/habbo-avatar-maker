Uma aplicação Web moderna, estática e ultrarrápida para geração e customização de avatares do ecossistema Habbo/Ravoatel. O sistema consome diretamente a API pública de imagens para fornecer uma experiência fluida de criação em tempo real, sem a necessidade de um back-end proprietário.

---

## ✨ Funcionalidades

* ⚡ **Live Preview em Tempo Real:** Veja as mudanças do seu avatar no exato momento em que ajusta os controles, com *debouncing* inteligente para máxima performance e respeito aos limites da API.
* ☁️ **100% Serverless (Static):** Toda a arquitetura foi desenhada para rodar diretamente no cliente. Sem banco de dados, sem back-end próprio — apenas o navegador e a API pública.
* ♿ **Acessibilidade de Ponta (A11y):** Foco extremo em usabilidade para Pessoas com Deficiência (PcD). 
  * Total suporte à navegação por teclado (`Tab`/`Shift+Tab`).
  * Regiões `aria-live="polite"` para feedback proativo em leitores de tela.
  * Uso correto de semântica HTML e `aria-labels`.
  * Marcadores e tipografia garantindo taxa de contraste WCAG AA.
* 📋 **Exportação Rápida:** Gere a URL final do seu avatar customizado e copie para a área de transferência com feedback visual de sucesso num único clique.

---

## 🚀 Como Utilizar

A forma mais fácil de usar o Gerador de Avatares é através da versão hospedada gratuitamente via **GitHub Pages**:

1. Acesse o link da aplicação: [Gerador de Avatares (GitHub Pages)](https://mr-gabrieloliveira.github.io/habbo-avatar-maker/).
2. Na área de controles à esquerda, digite um nome de usuário válido.
3. Brinque com os controles: altere o gesto, as ações de corpo, a direção do rosto e do corpo, e o tamanho do avatar.
4. Confira o resultado atualizando instantaneamente na tela de **Live Preview**.
5. Quando o avatar estiver perfeito, clique no botão **Copiar** abaixo da imagem para salvar o link direto para a sua arte.

## 🛠️ Como Rodar Localmente

Caso queira clonar o projeto para contribuir, fazer testes ou customizar a interface, o processo é super simples.

### Pré-requisitos
* **Node.js** (versão 18+ recomendada)
* **npm** ou **yarn**

### Instalação

```bash
# Clone este repositório
$ git clone https://github.com/Mr-GabrielOliveira/habbo-avatar-maker.git

# Acesse a pasta do projeto
$ cd habbo-avatar-maker

# Instale as dependências
$ npm install

# Inicie o servidor de desenvolvimento super veloz do Vite
$ npm run dev
```

A aplicação estará rodando e pronta para edições em `http://localhost:5173`.
